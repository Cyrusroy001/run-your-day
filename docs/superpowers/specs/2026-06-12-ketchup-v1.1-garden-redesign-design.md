# ketchup v1.1 — the garden redesign (design spec)

**Date:** 2026-06-12 · **Status:** approved by Cyrus (visual-companion session) · **Decision:** ADR-022
**Supersedes the presentation layer of** `2026-06-11-ketchup-full-visual-spec-v2.html` (engine/storage untouched).

## Why

First real-device QA of v1 (signed APK, S21 FE — widget rendered, ADR-010 unblocked) produced:
too moody, tomato red too aggressive, past tasks invisible after completion, timeline too long to
scroll, week planner still v3-looking and card-small, widget too plain. Cyrus also asked for an
original artistic identity and for every surface to honor the schema's generality (the moat).

## 1. Concept — ripeness = time

One metaphor runs the app. Every block is a fruit on today's vine:

| State | Color | Meaning |
| --- | --- | --- |
| unripe | green `#7E9A6B` | later today |
| ripening | `#B5A65A` | in a while |
| nearly | apricot `#E2A35F` | up next |
| **ripe** | red `#C8523C` | **NOW — the only red on screen, small and earned** |
| overripe/jammy | `#8E4540` (text `#9C4F43`) | missed/behind → squeeze ingredients |
| picked | vine green `#5F7050` | done — fruit leaves the vine, calyx stays |

You **climb the vine** through the day (future above, walked vine below), collecting picked fruit
into a **basket**. Overripe fruit is what ketchup is made from: drift isn't failure, it's
ingredients. Completing = **Pick ✓** (primary action verb app-wide).

### Palette (replaces tomato theme; keep the `context.c` token invariant)

- **Garden (light, primary):** ground cream `#F5EFE3`, card `#FFFCF5`, ink `#2E2718`,
  dim `#8A8170`, hairline `rgba(46,39,24,.12)`, today-tint amber `rgba(226,163,95,.65)`.
- **Greenhouse (dark):** soil ground `#211E16`, card `#2B271E`, same ripeness ramp.
- Primary action = vine `#5F7050` (Pick buttons, links). Ripe red is for NOW only — never fills,
  never large surfaces. App icon squiggle + launcher recolor to match.
- Token plan: keep `context.c` as the single color source; add ripeness ramp tokens; light/dark/auto
  setting unchanged.

### Ambient sun-clock

Home + widget grounds tint with the local-time sun: dawn rose → day cream → golden-hour amber →
dusk plum → night soil + stars. Pure local-clock curve (no location API). **Light always means
time; drift never recolors the sky** — being behind shows only in the vine (tension, jammy fruit).
Timeline/Week keep plain garden/greenhouse grounds.

### Night state

When the day's trackable plan is done (or the plan window ends): vine fully climbed, starry
ground, and a **small green bud** — tomorrow, as pure metaphor. **No task names, no times.**
Replaces "Nothing left today. / Go be a person."

## 2. Structure — 3 tabs

Bottom nav: **Today · Timeline · Week**. Catch-up + Settings + glossary stay in the avatar menu.
Adjust mode moves to the Timeline header. FAB (+ add task) stays on Today + Timeline.

## 3. Today (Home)

- **Sun-arc live card:** the day drawn as an arc across the plan's waking window (schema-driven,
  not hardcoded hours); fruit hung at their hours in ripeness colors; NOW glows on the curve;
  walked arc thickens. Picked = hollow calyx dots.
- **Hero** below the arc: `● RIPE NOW`, block name (full-width, large), time left + until-time,
  **Pick ✓**.
- **Glance cards:** Up next (next 2 stops) · This week (mini jar-shelf, replaces sparkline/percent)
  · Sunday catch-up chip when relevant · repeat-prompt + promotion cards as today.
- Whisper line and teach captions stay, re-voiced to garden copy.

## 4. Timeline — the living vine

- Vine climbs **upward**: future blocks above, NOW ripe inline (enlarged node), basket at ground.
- **Basket row at the bottom** of the walked vine: "🧺 n picked · m jammy ▾". Unfurling reveals the
  morning beneath it: picked = bare calyx + struck label (dimmed), un-tapped past blocks hang jammy
  with **pick late?** (tap = mark done; fixes the lost-toggle gap).
- **Drift made physical:** vine slack/curvy when caught up; pulls taut/straight as drift grows.
  Squeezed blocks show squashed fruit + "went over → squeezed −N min". Anchors = dashed-ring fruit
  (held), labels from the plan.
- **Adjust** button in the header (no scroll). Adjust mode keeps current behavior (reorder, skip
  today, Protect/Normal/Drop-first), restyled to garden cards.
- Pick animation: fruit drops toward the basket count (reduced-motion: instant state change).

## 5. Week — the allotment

- Full page: **7 plots in one garden picture** (grid), tap a plot → detail card below.
- Plot shows: day initial, template tint, modifier cage glyph(s). **Today = warm tint only, no
  glyph.** Detail card: template chips (tap = cycle the plan's templates) + modifier toggles.
- Constraint caption is **generated from each modifier's own rule** ("4 caged · well spaced ✓",
  "at limit"). PlannerLogic rules unchanged (exactly 4 training days, never adjacent — its
  messages re-voiced).
- "↻ Re-sow the suggested week" = existing applyBestSpacing.

## 6. Sunday review — the pantry

Each day bottles a **ketchup record**:

- **Quantity** = picked/trackable (existing adherence definition: `cls != work && cls != chill`).
  Shown as jar fill.
- **Quality** = batch grade from the day's drift data — *first press* (0 squeezes, 0 drops, 0 late
  picks), *good batch* (≤2 squeezes, 0 drops), *rough batch* (anything more). Copy generic, never
  gym-specific. Shown as jar label/tint.

Review = **7 jars on a shelf instead of percentages**. Existing insights stay, re-voiced: weekly
sentence (WeeklyReview.summarize) as the shelf caption, most-squeezed label + "give it more time",
promotion candidates. Wreath/poster art optional flourish here later — not required for v1.1.

**Data:** `DayKetchup {date, picked, trackable, squeezes, drops, latePicks, grade}` — derived from
existing AdherenceStore + drift log; persisted per day in the profile doc (file-per-profile
invariant; no new stores outside `ProfileRepository`). Home's jar-shelf card reads the same records.

## 7. Widget — painted arc

- The app pre-renders the sun-arc card (ambient tint included) to an image
  (`home_widget` renderFlutterWidget) on each data push / ~15-min WorkManager refresh; the arc
  crawls slowly so staleness is acceptable.
- Block name + times stay **native text** over/below the image, ~2× current size; tomato-calyx NOW
  dot; ripening-gradient progress; picked count; next stop.
- Night = stars + bud image, no text rows (metaphor only).
- **Fallback (risk control):** if image rendering misbehaves on One UI, ship the native-only "ripe
  card" layout (same content, vector tomato + gradient bar) — the pipeline proven this morning.

## 8. Generality invariant (the moat clause)

**No lifestyle constants in any widget.** Surfaces render only what the Life JSON declares:
template labels (cycle the plan's set), modifier chips + rule-generated captions, anchors, block
labels, the waking window. **Goals are 0..N tracks** — each may contribute blocks, a day-modifier
with its own rule, and progression semantics. Every surface degrades gracefully at 0 goals (chips
and captions simply absent) and scales at N (multiple cage chips per day, per-rule captions;
optional per-track lines in the pantry). Office/WFH/Train/Rest is Cyrus's data, not vocabulary.
The garden skin encodes only universal dimensions: time→ripeness, completion→picking,
drift→tension/jam, heavy-load modifier→cage.

## 9. Motion & accessibility

Subtle only: fruit sway (micro), vine tension ease, pick-drop, ambient tint crossfades. All gated
by reduced-motion (fall back to static botanical-plate styling). Contrast: ink-on-cream and
text-on-soil pairs must pass at 1.3× text scale (QA list).

## 10. Out of scope / unchanged

Drift engine, TimelineAssembler (still the only block source), golden test, file-per-profile
storage, notifications (K-notify as shipped), onboarding/AI/interview stack, in-app plan editor
(the Week detail card is not it). `buildTimes`/`writeWidgetData` invariants intact.

## 11. Build constraints

Release signing in place (`key.properties` + `C:/Users/Cyrus/ketchup-release.jks`, CN=cyrus).
